# 紧急地震速报中基于距离衰减公式的震度计算

这是 [地震情报应用界 Advent Calendar 2021](https://adventar.org/calendars/6729) 第16天的文章。

## 概述

使用距离衰减公式进行震度计算虽然无法做出精细的震度预测，但由于其计算非常简单，因此常被用于紧急地震速报等需要即时性的场景。

这是留给我自己的记录。

后半部分将提供使用 TypeScript 实现的示例。

## 计算公式

### M（震级）转换

距离衰减公式使用的是 $M_{W}$（矩震级），而紧急地震速报中计算出的 $M$ 是 $M_{JMA}$（日本气象厅震级），因此需要根据宇津（1982）的经验公式将 $M_{JMA}$ 转换为 $M_{W}$。

$$
M_{W} = M_{JMA} - 0.171
$$

### 最短距离的计算

使用宇津（1977）的公式，根据 $M$ 通过相似律计算出预测的断层长度，并假设震源断层是一个以此长度的 $1/2$ 为半径的球体。将其中心设置在震源处，该球面到计算点的距离即为最短距离。  
下面的公式用于计算断层长度 $L$：

$$
\log_{10} L = 0.5 M - 1.85
$$

这里的 $M$ 使用 $M_{W}$ 进行计算。

下面的公式通过断层长度 $L$ 的半径和震源距离 $x$ 来计算最短距离 $X$。单位均为 km。  
如果计算出的点到震源的距离小于 3km，则最短距离统一设定为 3km。

$$
X = \max \left(x - \left(L \cdot 0.5\right) , 3\right)
$$

### 距离衰减公式

利用估算的 $M_{W}$，通过距离衰减公式（司・翠川，1999）求出平均 S 波速度为 600m/s 的工程基岩上的最大速度 $PGV_{600}$。

$$
\log_{10} \left(PGV_{600}\right) = 0.58 M_{W} + 0.0038 D + d - \log_{10} \left(X + 0.0028 \cdot 10^{0.5 M_{W}}\right) - 0.002 X - 1.29
$$

其中，$D$ 是震源深度，$d$ 是不同地震类型的系数（内陆地壳地震：0、板块间地震：-0.02、板块内地震：0.12、紧急地震速报：0），$X$ 是最短距离。

### 最大速度的校正

为了校正工程基岩上的估算最大速度，需要乘以地表放大率。  
NIED（日本防灾科学技术研究所）公开了[表层地盘信息提供API](https://www.j-shis.bosai.go.jp/api-sstruct-meshinfo)，我们将使用其中出现的“从工程基岩（Vs=400m/s）到地表的最大速度放大率”。  
为了符合气象厅预报业务许可的要求，请使用 V2 版本。

由于估算最大速度和作为校正值的放大率所对应的工程基岩 S 波平均速度不同，需要进行统一。先求出从工程基岩（Vs=600m/s）转换到工程基岩（Vs=400m/s）的放大率（松冈・翠川 [1994]），然后使用它进行转换。

放大率是指地震波从工程基岩传到地表或另一工程基岩时被放大的倍数。

从工程基岩（Vs=600m/s）转换到工程基岩（Vs=400m/s）的放大率计算如下：

$$
ARV = \left( 600 \div 400 \right)^{0.66} \cong 1.31
$$

接下来将使用一个简便的放大率，即 1.31。

$$
PGV_{400} = PGV_{600} \times 1.31
$$

然后，

$$
PGV_{S} = PGV_{400} \times ARV
$$

即可得到地表的估算最大速度 $PGV_{S}$。

不过，这里的 $ARV$ 是指前面 API 中提到的“从工程基岩（Vs=400m/s）到地表的最大速度放大率”。

### 计测震度的计算

算出了估算最大速度后，震度的计算就易如反掌了。

$$
I_{INSTR} = 2.68 + 1.72 \cdot \log_{10} \left(PGV_{S}\right) \pm 0.21
$$

$I_{INSTR}$ 即为计测震度。

## 实现

具体的实现使用的是**“我”**最喜欢用的 TypeScript。

这里假设震度计算的震源初始值为以下数据：

```typescript
// 震级 (Mjma)
const magJMA = 7.0;

// 深度 (km)
const depth = 10;

// 震中 (这里取纬度 39.5°, 经度 135° 的日本海)
const epicenterLocaltion = [39.5, 135];
```

转换震级 M 并计算震源断层长度。

```typescript
// 震级 (Mw)
const magW = magJMA - 0.171;

// 断层长度 (半径)
const long = 10 ** (0.5 * magW - 1.85) / 2;
```

接下来，求出在任意地点预测的工程基岩上 (Vs=600m/s) 的最大速度。

```typescript
// 想要预测的地点 (这里以福岛县磐城市役所为例)
const pointLocaltion = [37.050475, 140.887327];

// 计算震中与想要预测的地点的直线距离 (km)
// (函数的具体实现省略)
const epicenterDistance = geoDistance(epicenterLocaltion, pointLocaltion);

// 计算减去断层长度后的震源距离
const hypocenterDistance = (depth ** 2 + epicenterDistance ** 2) ** 0.5 - long;

// 由于计算中使用的最短震源距离为 3km，因此取较大值
const x = Math.max(hypocenterDistance, 3);

// 工程基岩上 (Vs=600m/s) 的最大速度
const gpv600 = 10 ** (
      0.58 * magW +
      0.0038 * depth - 1.29 -
      Math.log10(x + 0.0028 * (10 ** (0.5 * magW))) -
      0.002 * x
);
```

对于每个预测地点，将其从工程基岩上 (Vs=600m/s) 进行校正。

```typescript
// 预测地点的工程基岩 (Vs=400m/s) 到地表的最大速度放大率 (这里为了简便设为 1.0，即不放大)
const arv = 1.0;

// 将最大速度从工程基岩 (Vs=600m/s) 转换到工程基岩 (Vs=400m/s)
const pgv400 = gpv600 * 1.31;

// 计算地表上的估算最大速度
const pgv = pgv400 * arv;
```

最后计算计测震度。

```typescript
// 将预测地点的地表估算最大速度转换为计测震度
const intensity = 2.68 + 1.72 * Math.log10(pgv);
```

到这里就完成啦。

# 緊急地震速報で使われる距離減衰式による震度計算 (原文)

これは [地震情報アプリ界隈 Advent Calendar 2021](https://adventar.org/calendars/6729) の16日目の記事です。

## 概要

距離減衰式は震度計算は細かい震度予測ができない反面、計算が非常に簡単なもののため、緊急地震速報など即時性が必要とされる場合に使われます。

これは、自分への記録です。

後半にはTypeScriptによる実装を例を掲載します。

## 計算式

### M変換

距離減衰式では $M_{W}$ を使用しますが、緊急地震速報で算出される $M$ は $M_{JMA}$ （気象庁マグニチュード）のため、宇津(1982)の経験式により $M_{JMA}$ を $M_{W}$ へ変換します。

$$
M_{W} = M_{JMA} - 0.171
$$

### 最短距離の計算

宇津（1977）の式を用いて $M$ から相似則により予測される断層の長さを算出し、その1/2を半径とした球を震源断層と仮定します。その中心を震源に設置し、その球面からの距離を最短距離とします。  
下記の式では、断層長 $L$ を算出します。

$$
\log_{10} L = 0.5 M - 1.85
$$

ここでの $M$ は $M_{W}$ として計算します。

下記の式では断層長 $L$ の半径と震源距離 $x$ から最短距離 $X$ を算出します。単位はいずれもkmです。  
計算した地点と震源の距離が3km未満となるについては、一律で最短距離を3kmに設定します。

$$
X = \max \left(x - \left(L \cdot 0.5\right) , 3\right)
$$

### 距離減衰式

推定された $M_{W}$ を用いて距離減衰式（司・翠川、1999）により平均S波速度速度600m/sの工学基板上の最大速度、 $PGV_{600}$ を求めます。

$$
\log_{10} \left(PGV_{600}\right) = 0.58 M_{W} + 0.0038 D + d - \log_{10} \left(X + 0.0028 \cdot 10^{0.5 M_{W}}\right) - 0.002 X - 1.29
$$

ここで、 $D$ は震源の深さ、 $d$ は地震タイプ別の係数（内陸地殻地震: 0、プレート間地震:-0.02、プレート内地震:0.12、緊急地震速報:0）、 $X$ は最短距離です。

### 最大速度の補正

工学的基板上の推定最大速度を補正するために、地盤増幅度を乗算します。  
NIEDが [表層地盤情報提供API](https://www.j-shis.bosai.go.jp/api-sstruct-meshinfo) を公開していますので、これに出現する「工学的基盤（Vs=400m/s）から地表に至る最大速度の増幅率」を使います。  
気象庁予報業務許可に適合するためにはV2を使用してください。

推定最大速度と補正値となる増幅率の工学的基盤のS波平均速度が異なるため合わせます。工学的基盤（Vs=600m/s）から工学的基盤（Vs=400m/s）へ変換を行う増幅率(松岡・翠川\[1994\])を求め、それにより変換を行います。

増幅率とは、工学的基盤上からどれぐらい増幅されて地表面・別の工学的基盤上で揺れるか示す倍率です。

工学的基盤（Vs=600m/s）から工学的基盤（Vs=400m/s）へ変換を行う増幅率は次で求めます。

$$
ARV = \left( 600 \div 400 \right)^{0.66} \cong 1.31
$$

ここからは簡便的な増幅率、1.31を使用します。

$$
PGV_{400} = PGV_{600} \times 1.31
$$

として、

$$
PGV_{S} = PGV_{400} \times ARV
$$

で、地表面での推定最大速度 $PGV_{S}$ を得ます。

ただし、 $ARV$ は先ほどAPIで説明した「工学的基盤（Vs=400m/s）から地表に至る最大速度の増幅率」です。

### 計測震度の算出

推定最大速度が出れば震度は楽勝です。

$$
I_{INSTR} = 2.68 + 1.72 \cdot \log_{10} \left(PGV_{S}\right) \pm 0.21
$$

$I_{INSTR}$ は計測震度です。

## 実装

実装は**"私が"**いつも使うTypeScriptちゃんです。

震度計算の震源初期値は仮で次の通りとします。

```typescript
// マグニチュード(Mjma)
const magJMA = 7.0;

// 深さ(km)
const depth = 10;

// 震央(ここでは緯度39.5°,経度135°の日本海)
const epicenterLocaltion = [39.5, 135];
```

Mの変換及び震源断層長を求めます。

```typescript
// マグニチュード(Mw)
const magW = magJMA - 0.171;

// 断層長(半径)
const long = 10 ** (0.5 * magW - 1.85) / 2;
```

次は、任意の地点で予測される工学基板上(Vs=600m/s)の最大速度を求めます。

```typescript
// 予測したい場所(ここでは福島県いわき市役所)
const pointLocaltion = [37.050475, 140.887327];

// 震央と予測したい場所の直線距離を求める(km)
// 関数の内容は省略する
const epicenterDistance = geoDistance(epicenterLocaltion, pointLocaltion);

// 断層長を引いた震源距離を求める
const hypocenterDistance = (depth ** 2 + epicenterDistance ** 2) ** 0.5 - long;

// 計算で使用する震源距離の最短は3kmなので、大きいほうを取る
const x = Math.max(hypocenterDistance, 3);

// 工学基板上(Vs=600m/s)の最大速度
const gpv600 = 10 ** (
      0.58 * magW +
      0.0038 * depth - 1.29 -
      Math.log10(x + 0.0028 * (10 ** (0.5 * magW))) -
      0.002 * x
);
```

工学基板上(Vs=600m/s)から予測地点ごとに補正をします。

```typescript
// 予測する地点の工学的基盤（Vs=400m/s）から地表に至る最大速度の増幅率(ここでは簡便的に1.0とする、つまり増幅しない)
const arv = 1.0;

// 最大速度を工学的基盤（Vs=600m/s）から工学的基盤（Vs=400m/s）へ変換を行う
const pgv400 = gpv600 * 1.31;

// 地表面での推定最大速度を求めます
const pgv = pgv400 * arv;
```

最後に計測震度を求めます

```typescript
// 予測する地点の地表面推定最大速度から計測震度への変換
const intensity = 2.68 + 1.72 * Math.log10(pgv);
```

以上、完了です。
